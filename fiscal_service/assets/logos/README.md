# Diretório de Logotipos das Filiais (DANFE & Interface)

Coloque aqui os arquivos de imagem das logos das filiais com fundo transparente ou branco (.png):

1. `credcell.png` - Logotipo da filial Cred Cell / Matriz
2. `monkeyshop.png` - Logotipo da filial Monkey Shop / Partage Shopping
3. `default.png` - Logotipo padrão / fallback para outras filiais ou operações gerais

### Dimensões Recomendadas
- Formato: PNG
- Resolução recomendada: Largura de 300px a 600px, altura de 120px a 240px (proporcional).
- O gerador de DANFE ajustará a imagem dinamicamente para caber no quadro do emitente (até 70pt de altura).
